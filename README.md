# Star Dodger

A touch-first mobile arcade game in plain HTML5 canvas — no build step.

Drag your finger to steer the ship, collect stars, dodge asteroids. Speed ramps up over time; you have 3 lives.

## Run

    python3 -m http.server 8000

Open `http://<your-ip>:8000` on your phone (same Wi-Fi), then "Add to Home Screen" for fullscreen play.
